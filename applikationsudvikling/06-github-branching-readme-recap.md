## Opgaver



### Opgave 1 - basis setup & readme fil

Lav et nyt github repo til jeres projekt, hvor der ligger et androidprojekt og en `README.md` fil

 Lav det ved én computer. Den `README.md` fil skal tilføjes til `main` branchen som vi plejer. Alle gruppemedlemmer skal nu pull `main` og se at de har `README.md` filen og androidprojektet lokalt.



### Opgave 2 - lav et godt setup til jeres heart-2-heart

Tænk over arkitekturen. I har måske allerede noget fra sidste gang med navigation. Tænk over det følgende:

- En god struktur. Hvordan vil i have jeres packages? Hvor vil i gemme jeres ui (komponenter), modeller, viewmodels
- Simpel navigation mellem to skærme. Man skal kunne gå frem og tilbage (det har i måske allerede lavet)
- En viewModel der har noget helt simpelt state eller en simpel funktion



Lav en liste af features i vil implementere. Hvert gruppemedlem tager en feature og brancher ud. Tilføjer commits og forsøger så at merge via et pull request. Det pull request skal godkendes af andre



### Opgave 3

Kl 10:15 skal i præsentere jeres app og jeres struktur for en anden gruppe. I kan lave den som en rigtig præsentation eller bare snakke det igennem mens i viser kode. I skal komme ind på noget af det følgende:

- Hvorfor har i valgt den arkitektur i har?
- Hvad har i overvejet og diskuteret ift jeres arkitektur?
- Hvad er fordele og ulemper ved den arkitektur i har valgt?
